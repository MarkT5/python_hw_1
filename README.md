Задание2.

Отсортировать списки имён по алфавиту и вывести людей с одинаковыми индексами после сортировки.

Вывести сообщение, если количество имён в списках не совпадает

При следующих входных данных:
```
boys = ['Peter', 'Alex', 'John', 'Arthur', 'Richard']
girls = ['Kate', 'Liza', 'Kira', 'Emma', 'Trisha']
```
выводится на экран:
```
Идеальные пары:
Alex и Emma
Arthur и Kate
John и Kira
Peter и Liza
Richard и Trisha.
```
При следующих входных данных:
```
boys = ['Peter', 'Alex', 'John', 'Arthur', 'Richard', 'Michael']
girls = ['Kate', 'Liza', 'Kira', 'Emma', 'Trisha']
```
выводится на экран:
```
Внимание, кто-то может остаться без пары!
```
